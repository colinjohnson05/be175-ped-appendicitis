# be175-ped-appendicitis
Cost-aware model for predicting pediatric appendicitis for BIOENGR 175 Final Project

## Introduction
This project introduces a new method to analyze and develop models for predicting clinical diagnoses

## Usage
Make sure to install all packages listed in ```~\requirements.txt```

### To run project in command line:
Activate your python environment

Navigate to the project root directory

Navigate to ```~\code```

Run ```python pipeline.py``` or ```python3 pipeline.py```

Results are output into ```~\results```

### To run units tests:

Navigate to ```~\tests```

Run ```python -m unittest discover``` or ```python3 -m unittest discover```
